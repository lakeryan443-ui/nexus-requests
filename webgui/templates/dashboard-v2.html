Discord Bot

Discord notification and approval cards

Create Notification Bot

Follow these steps to set up your Nexus Requests notification bot.

1. Create your Discord application

Open the Discord Developer Portal, select New Application, and name it Nexus Requests. Then open its Bot page.

Open Discord Developer Portal ↗
2. Connect your bot

Copy the Application ID from General Information and the bot token from Bot. Keep the token private.

3. Invite the bot

A future version will generate the invite link and verify the required permissions.

4. Create the notification channel

After authorization, Nexus Requests will find or create #nexus-requests in the selected server, without making duplicates.

5. Verify and activate

A future connection test will confirm permissions and send a test notification.

Find it: Developer Portal → Your App → General Information → Application ID

Find it: Enable Developer Mode in Discord → right-click your server → Copy Server ID.

Find it: Discord Developer Portal → Applications → Your App → Bot → Token

ⓘ Required Discord permissions

Your bot must be allowed to View Channels, Send Messages, Embed Links, Read Message History and Manage Channels (for automatic channel creation). Nexus Requests will request these during setup. You can remove Manage Channels after the channel is created.
